This is the project that I made because I want to study about how to implement L-System to create growing tree determine by rules in Unity.

There is a separate approach on 2d and 3d space which user can toggle in editor.

I use Unity’s Scriptable Object to modify the rules and record the rule data and Unity's splines for the branch visual.
